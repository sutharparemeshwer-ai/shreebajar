# Shree Bajar Design System & Visual Architecture

## Brand Palette
- **Primary Background**: Deep Midnight Sapphire (`#0B0F17`, `#0F172A`)
- **Primary Accent**: Emerald Teal (`#10B981`, `#059669`)
- **Secondary Accent**: Warm Amber Gold (`#F59E0B`, `#D97706`)
- **Glass Panel**: `rgba(15, 23, 42, 0.7)` with `backdrop-filter: blur(16px)` and border `rgba(255, 255, 255, 0.1)`
- **Typography**: Inter / Sans-Serif clean modern typography

## Three.js Visual Aesthetic Guidelines
- **Hero Canvas**: Interactive particle mesh with mouse-position dynamic rotation and floating metallic nodes representing a connected marketplace network.
- **Globe Canvas**: Rotating 3D wireframe / point-cloud sphere showing global connectivity and regional merchant nodes.
- **Card Interactive 3D**: Subtle CSS 3D matrix tilt on hover (`transform: perspective(1000px) rotateX(...) rotateY(...)`).

## 4 Core Page Layouts
1. **Home**: High impact 3D hero, live stats counter, core value proposition, featured services showcase, merchant trust badges, interactive call-to-action.
2. **Services**: Comprehensive breakdown of B2C E-Commerce Solutions, B2B Merchant Hub, AI Analytics Suite, and Seamless Payment/Logistics Integration with interactive tabs and filters.
3. **About Us**: Startup origin story, vision & mission, interactive milestone timeline, leadership team cards, visual 3D company network.
4. **Contact**: Interactive multi-purpose inquiry form, direct contact options (Email, Phone, WhatsApp, Office Locations), interactive 3D location node, interactive FAQ accordion.
